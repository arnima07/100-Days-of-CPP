# Day 03 - Loops in C++

## Topics Covered
- for loop
- while loop
- Iteration and repetition
- Basic number problems

## Problems Solved

### 4. Multiplication Table

### 5. Factorial of a Number
Find the factorial of a given number using loops.

## Concepts Learned
- Using `for` loops
- Loop initialization, condition, and increment
- Performing repetitive tasks efficiently
- Accumulating values using loops
